# Finance Tracker

A simple and modern Finance Tracker web application built using React and Vite.

## Features
- Add income and expense transactions
- Real-time balance calculation
- Transaction history logs
- Delete transactions
- Responsive UI
- SPA navigation using React Router
- Smooth animations using Framer Motion

## Technologies Used
- React JS
- Vite
- Tailwind CSS
- React Router DOM
- Framer Motion
- React Icons

## Run Locally

```bash
npm install
npm run dev
